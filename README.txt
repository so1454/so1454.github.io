팝콘 인터랙션 웹

실행: index.html을 브라우저에서 열면 됩니다. 별도 설치가 필요 없습니다.
버튼 클릭 / 모바일 터치 / Space / Enter로 팝콘을 터뜨릴 수 있습니다.
계속 클릭할 수 있으며, 로고나 엔딩 화면은 표시되지 않습니다.

index.html — 페이지
style.css — 화면과 버튼 스타일
app.js — 버튼 반동과 팝콘 물리 모션
audio-data.js — 선택한 레이니75 영상에서 추출한 6개 타건음 데이터
assets/ — 제공된 영상에서 추출한 버튼·팝콘 이미지 및 클릭 효과음
AUDIO-CREDITS.txt — 효과음 원본 출처

클릭할 때마다 짧은 조약돌 타건음이 번갈아 재생됩니다.
연속 클릭 시 각 소리가 겹쳐 재생되며 앞 소리가 중간에 끊기지 않습니다.
소리는 클릭했을 때만 나며, 인터넷 연결 없이 실행할 수 있습니다.

popcorn.html은 모든 이미지와 코드를 한 파일에 포함한 버전입니다.
